# Panduan Pengguna Marketing

**Marketing Bias Growth (MBG)** · Diperbarui 26 Oktober 2026

Panduan ini untuk pengguna dengan role **Marketing Operator**. Tujuan pekerjaan Anda adalah mengumpulkan calon penerima dari followers TikTok, menyimpan datanya, mengirim DM, dan melakukan follow-up.

## Mulai dari sini

**Persiapan sekali di awal:** masuk ke MBG → tambahkan akun TikTok → pasang dua extension.

**Alur kerja harian:** pilih akun pengirim → ambil dan simpan followers bila diperlukan → pilih penerima dan pesan → masukkan ke antrean → mulai DM Sender → periksa hasil.

Sudah punya penerima tersimpan? Langsung gunakan **Kirim DM** tanpa mengambil followers lagi. Sudah pernah menghubungi penerima? Buka pesan lamanya dan gunakan **Buat follow-up**.

## 1. Mengenal menu dan data Anda

| Menu                 | Kegunaan                                                                                                 |
| -------------------- | -------------------------------------------------------------------------------------------------------- |
| Dashboard            | Melihat ringkasan akun, followers tersimpan, jumlah DM, dan pengiriman yang perlu diperiksa.             |
| Akun TikTok          | Menambahkan dan memperbarui akun yang Anda gunakan sebagai pengirim.                                     |
| Outbound Workstation | Tempat bekerja: halaman **Kirim DM TikTok**, pengambilan followers, pengiriman, follow-up, dan template. |
| Pengaturan           | Mengatur profil dan keamanan, termasuk password, verifikasi dua langkah, serta sesi aktif.               |
| Disclaimer           | Membaca penjelasan pengelolaan dan penggunaan data perusahaan. Ada di bagian bawah menu.                 |

Anda bekerja dengan akun dan data milik pengguna Anda sendiri. Data marketing lain tidak digabungkan ke tampilan Anda. Super Admin dapat melihat seluruh data sesuai kewenangannya.

Template rekomendasi admin tersedia bersama. Template pribadi Anda terpisah dari template marketing lain; Super Admin tetap dapat mengaksesnya. Halaman **CRM / Prospek** dan **AI Sales Agent** tidak ditampilkan untuk role Marketing.

## 2. Login dan keluar dari aplikasi

1. Buka alamat MBG yang diberikan admin.
2. Masukkan email dan password akun kerja, lalu klik **Masuk**.
3. Jika verifikasi dua langkah aktif, masukkan kode dari aplikasi authenticator.
4. Setelah masuk, periksa nama pengguna di kanan atas agar tidak memakai akun rekan kerja.

Untuk keluar, klik nama/foto pengguna di kanan atas lalu pilih **Keluar**.

**Sesi otomatis berakhir setelah 30 menit tanpa aktivitas di dashboard.** Peringatan muncul satu menit sebelumnya. Klik **Tetap masuk** atau lanjutkan aktivitas untuk memperpanjang sesi. Aktivitas di salah satu tab MBG juga memperpanjang sesi di tab lain untuk pengguna yang sama.

Gerakan pointer, klik, ketikan, scroll, dan sentuhan dihitung sebagai aktivitas. Pembaruan data otomatis dan proses extension tidak dihitung. Saat pengiriman berlangsung, tetap pantau dashboard; jika sesi berakhir, login kembali dan periksa status sebelum melanjutkan. Setelah laptop sleep, sesi yang sudah melewati batas akan berakhir saat dashboard aktif kembali.

## 3. Menambahkan akun TikTok

Login MBG dan login TikTok adalah dua hal berbeda. Menambahkan akun di MBG **tidak otomatis membuat TikTok login** di browser.

1. Buka **Akun TikTok** dan klik **Tambah akun**.
2. Isi form berikut.
3. Klik **Tambah akun** untuk menyimpan.

| Kolom              | Cara mengisi                                                                                                         |
| ------------------ | -------------------------------------------------------------------------------------------------------------------- |
| Username TikTok    | Username akun pengirim, misalnya `@contoh.marketing`. Gunakan akun yang memang Anda kelola.                          |
| Jenis akun         | Pilih sesuai akun yang Anda gunakan, misalnya Personal.                                                              |
| Jumlah followers   | Isi jumlah followers yang terlihat pada profil. Ini catatan manual, bukan jumlah calon penerima yang sudah disimpan. |
| URL profil (wajib) | Tautan lengkap profil, misalnya `https://www.tiktok.com/@contoh.marketing`. Harus diawali `https://`.                |
| Akun terverifikasi | Aktifkan hanya jika akun benar-benar memiliki centang biru TikTok.                                                   |

Akun baru otomatis berstatus **Aktif** dan nama tampilannya mengikuti username. Kedua kolom tersebut
tidak perlu diisi. Mengedit akun lama tetap mempertahankan nama tampilan dan status yang sudah tersimpan.

Tidak perlu memasukkan password TikTok ke form MBG. Login TikTok dilakukan langsung di situs TikTok.

## 4. Memasang extension: cukup sekali di awal

Gunakan Chrome atau Microsoft Edge di komputer. Ada **dua extension berbeda**:

| Extension                             | Digunakan saat                                                       |
| ------------------------------------- | -------------------------------------------------------------------- |
| **SMGE · Followers / SMGE Followers** | Membaca daftar followers yang terlihat dan mengekspor file hasilnya. |
| **SMGE DM Sender**                    | Mengirim pesan yang sudah Anda masukkan ke antrean MBG.              |

Nama extension masih memakai **SMGE** meskipun nama aplikasi sudah Marketing Bias Growth.

### Mengunduh kedua extension

- Untuk pengambil followers: buka **Outbound Workstation → Ambil followers → Unduh extension**.
- Untuk pengirim DM: buka **Status pengiriman → Pasang extension / bantuan pengiriman → Unduh DM Sender**.

### Memasang setiap extension

1. Ekstrak file ZIP yang diunduh. Jangan langsung memilih file ZIP saat pemasangan.
2. Buka `chrome://extensions` untuk Chrome atau `edge://extensions` untuk Edge.
3. Aktifkan **Developer mode / Mode pengembang**.
4. Klik **Load unpacked / Muat yang belum dipaketkan**.
5. Pilih folder hasil ekstrak yang berisi file `manifest.json`.
6. Ulangi untuk extension satunya. Folder keduanya berbeda.
7. Klik ikon puzzle **Extensions** pada browser, lalu pin kedua extension agar mudah dibuka.

Jika perusahaan membatasi pemasangan extension, minta bantuan admin. Saat ada pembaruan extension, unduh versi terbaru, ekstrak, lalu perbarui folder pemasangan dan klik **Reload / Muat ulang** pada halaman Extensions. Refresh dashboard saja tidak memperbarui extension.

## 5. Memilih akun pengirim

1. Buka **Outbound Workstation**. Judul halaman Marketing adalah **Kirim DM TikTok**.
2. Pilih akun pada dropdown di kanan atas, misalnya `@contoh.marketing`.
3. Di browser yang sama, buka TikTok dan login sebagai akun pengirim tersebut.

**Akun di dropdown MBG harus cocok dengan akun yang login di TikTok saat mengirim.** Jika berbeda, ganti pilihan MBG atau akun login TikTok terlebih dahulu.

## 6. Mengambil dan menyimpan followers

Langkah ini menghasilkan daftar calon penerima; belum mengirim pesan kepada siapa pun.

1. Dari halaman **Kirim DM TikTok**, pilih akun pengirim lalu klik **Ambil followers**.
2. Klik **Buka profil**, atau buka profil akun sumber lain yang Anda kelola di TikTok.
3. Pada profil TikTok, buka **Followers / Pengikut**. Pastikan bukan **Following / Mengikuti**.
4. Saat tab TikTok aktif, buka extension **SMGE Followers**.
5. Centang konfirmasi bahwa Anda membuka daftar followers akun yang Anda kelola, lalu klik **Mulai**.
6. Tunggu proses membaca daftar yang tampil. Gunakan **Hentikan** jika ingin berhenti.
7. Klik **Ekspor JSON** dan simpan file hasilnya. Popup extension boleh ditutup, tetapi **jangan refresh atau menutup tab TikTok sebelum ekspor**.
8. Kembali ke dialog **Ambil followers** di MBG.
9. Pada **File hasil pengambilan (.json)**, pilih file yang baru diekspor.
10. Periksa akun sumber dan pratinjau username, kemudian klik **Simpan ke database**.
11. Buka tab **Antrean prospek** untuk melihat calon penerima yang memenuhi syarat.

**Akun sumber boleh berbeda dengan akun pengirim.** Contoh: Anda memilih akun pengirim A di MBG, tetapi file berisi followers akun sumber B. Data disimpan untuk akun pengirim yang Anda pilih, sementara asal akun sumber tetap dicatat. Pastikan pilihan pengirim sudah benar sebelum menyimpan.

Pengambilan dibatasi **maksimal 250 username per batch**, tetapi hasil nyata bisa lebih sedikit. Hasil 31 akun tidak otomatis berarti aplikasi memiliki batas 31; daftar yang terlihat, proses pemuatan TikTok, dan kondisi halaman memengaruhi hasil. Sistem tidak menjamin semua followers akan terambil.

Saat file yang sama diunggah kembali, data duplikat tidak ditambahkan ulang. Akun sendiri, penerima dalam daftar larangan kontak, dan entri yang tidak memenuhi syarat dapat dilewati. Mengikuti akun TikTok tidak otomatis berarti memberi persetujuan menerima pesan.

## 7. Mengirim DM

### Pilih penerima dan siapkan pesan

1. Pastikan akun pengirim pada dropdown sudah benar.
2. Klik tombol kuning **Kirim DM**.
3. Centang penerima yang ingin dihubungi. **Pilih sesuai kuota** membantu memilih sejumlah penerima sesuai sisa kuota.
4. Pada **Pakai template**, pilih template atau tulis pesan sendiri.
5. Periksa contoh pesan yang sudah menampilkan nama penerima dan akun pengirim.
6. Klik **Tinjau pengiriman**. Periksa pengirim, jumlah penerima, dan isi pesan masing-masing.
7. Klik **Masukkan ke antrean**.
8. Klik **Lihat status & mulai extension** untuk kembali ke halaman utama.

Tidak ada langkah persetujuan Admin untuk alur ini. Kuota dan jumlah maksimum penerima mengikuti angka yang tampil di aplikasi; jangan menganggap pengambilan 250 followers berarti bisa langsung mengirim 250 DM.

Untuk satu orang, buka **Antrean prospek**, cari nama atau username, lalu klik **Kirim DM** pada baris orang tersebut. Penerimanya langsung terpilih.

### Mulai pengiriman melalui browser

1. Pastikan TikTok sudah login sebagai akun pengirim yang dipilih.
2. **Aktifkan tab MBG / Outbound**, lalu buka extension **SMGE DM Sender**.
3. Centang konfirmasi bahwa penerima dan pesan sudah Anda periksa.
4. Klik **Mulai dari tab Outbound ini**. Jika diminta, izinkan akses ke alamat dashboard MBG.
5. Biarkan tab MBG tetap terbuka dan login. Extension membuka atau memakai tab TikTok untuk memproses penerima.
6. Pantau hasil pada panel **Status pengiriman**; data diperbarui sekitar setiap lima detik.

**Masuk antrean belum berarti pesan terkirim.** Pengiriman dimulai melalui DM Sender. Hindari mengubah chat atau mengetik pada tab TikTok yang sedang diproses. Tutup DevTools / Inspect pada tab tersebut selama pengiriman.

### Memahami status pengiriman

| Status                           | Artinya dan tindakan Anda                                                                                                                                                |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Menunggu extension               | Pesan sudah masuk antrean. Mulai DM Sender dari tab Outbound.                                                                                                            |
| Diproses                         | Pesan sedang ditangani. Tunggu hasilnya; jangan membuat kiriman ulang.                                                                                                   |
| Terlihat terkirim / dikonfirmasi | Pesan teramati di chat atau dicatat terkirim setelah pemeriksaan operator. Ini bukan bukti pesan sudah dibaca.                                                           |
| Gagal                            | Baca alasan, periksa chat TikTok, lalu gunakan **Antrekan ulang** hanya jika yakin pesan belum terkirim. Setelah itu mulai extension lagi bila diperlukan.               |
| Belum terverifikasi              | Hasil belum pasti. Buka chat dan pilih **Sudah diperiksa: terkirim** atau **Sudah diperiksa: tidak terkirim** sesuai keadaan sebenarnya. Jangan memilih tanpa memeriksa. |
| Dibatalkan                       | Pesan yang masih menunggu sudah dibatalkan. Tidak akan dikirim dari antrean tersebut.                                                                                    |

Jika hasil **Belum terverifikasi**, selesaikan pemeriksaan terlebih dahulu karena antrean akun dapat tertahan. Jika ditandai tidak terkirim, periksa status hasilnya dan gunakan **Antrekan ulang** bila tersedia. Sistem tidak otomatis mengulang percobaan yang hasilnya belum jelas.

## 8. Follow-up tanpa jadwal

Balasan TikTok belum diambil otomatis oleh MBG. Karena itu, Anda **tidak perlu menunggu status dibalas** untuk menyiapkan follow-up TikTok. Tidak perlu membuat tanggal atau jam follow-up.

1. Pada hasil terkirim, klik **Buka tugas / follow-up**. Alternatifnya, buka **Pesan & follow-up → Sudah dikirim**, lalu klik pesan penerima.
2. Klik **Buat follow-up**.
3. Isi **Pesan follow-up baru**. Tulis pesan sesuai percakapan terakhir yang Anda lihat di TikTok.
4. Periksa pratinjau nama, pengirim, isi, dan link.
5. Klik **Masukkan follow-up ke antrean**.
6. Jalankan **SMGE DM Sender** dari tab Outbound seperti saat mengirim pesan pertama.

Jika follow-up sudah berstatus **Follow-up** tetapi belum masuk antrean, buka pesannya lalu klik **Masukkan ke antrean**. Jangan membuat pesan baru berkali-kali untuk penerima yang sama. Periksa pesan yang masih menunggu, sedang diproses, atau belum terverifikasi terlebih dahulu.

## 9. Membuat dan mengubah template pribadi

Template membantu memakai ulang teks. Anda tetap bisa mengubah isi pesan pada form **Kirim DM** sebelum mengantrekannya; perubahan pada kiriman itu tidak otomatis mengubah template tersimpan.

### Membuat template sendiri

1. Buka **Outbound Workstation → Template**.
2. Klik **Template baru**.
3. Isi **Nama** yang mudah dikenali, misalnya `Perkenalan singkat saya`.
4. Pilih **Tujuan** yang sesuai, misalnya Perkenalan atau Follow-up.
5. Isi **Isi pesan**, aktifkan **Aktif**, lalu klik **Simpan**.
6. Template muncul pada **Template saya** dan dapat dipilih ketika menyiapkan DM.

Gunakan ikon pensil untuk mengedit template pribadi. Gunakan ikon tempat sampah untuk menghapusnya dan baca konfirmasi sebelum melanjutkan. Jika hanya ingin berhenti memakainya sementara, edit template dan matikan **Aktif**.

### Memakai rekomendasi admin

Template di bagian **Rekomendasi admin** bisa langsung dipakai. Untuk mengubahnya menjadi versi sendiri, klik **Salin ke template saya**, ubah nama atau isinya, lalu klik **Simpan sebagai template saya**. Salinan tersebut menjadi template pribadi Anda; rekomendasi aslinya tidak berubah.

### Mengisi nama dan link secara otomatis

| Teks dalam template | Hasil saat mengirim                                                                             |
| ------------------- | ----------------------------------------------------------------------------------------------- |
| `{{nama}}`          | Nama penerima yang tersimpan; periksa pratinjau karena nama hasil pengambilan bisa kurang rapi. |
| `{{username}}`      | Username TikTok penerima.                                                                       |
| `{{akun}}`          | Username akun pengirim. Gunakan `@{{akun}}` jika ingin menampilkan tanda `@`.                   |
| `{{link}}`          | Link yang sudah dikonfigurasi pengelola. Jika belum tersedia, ganti dengan URL lengkap.         |

Contoh pesan perkenalan:

```text
Halo {{nama}}, aku dari @{{akun}}. Terima kasih sudah mengikuti konten kami.
Boleh aku kirim informasi singkat yang mungkin sesuai dengan minat Kakak?
```

Contoh follow-up yang bisa ditempel dan disesuaikan:

```text
Halo {{nama}}, aku ingin melanjutkan percakapan sebelumnya.
Apakah masih ada informasi yang ingin ditanyakan?
```

Untuk link sendiri, tempel langsung seperti `https://example.com/informasi`, **tanpa** `{{ }}`. Jangan menulis `{{https://example.com/informasi}}`. Placeholder `{{campaign}}` hanya dapat dipakai jika data campaign tersedia; untuk alur Marketing ini, gunakan empat placeholder dalam tabel atau teks biasa.

Pesan yang dikirim harus berisi 5–2.000 karakter dan seluruh variabelnya harus dapat diisi. Selalu lihat hasil personalisasi pada **Tinjau pengiriman**, terutama nama dan link.

## 10. Membatalkan dan menghapus antrean yang dibatalkan

**Untuk membatalkan yang belum diproses:** pada panel **Status pengiriman**, klik **Batalkan yang menunggu**. Tombol ini membatalkan pesan menunggu untuk akun pengirim yang sedang dipilih, bukan hanya satu baris.

**Untuk menghentikan extension:** buka DM Sender dan klik **Hentikan setelah pesan ini**. Percobaan yang sedang berjalan akan diselesaikan lebih dahulu; tindakan ini bukan penarikan pesan yang sudah terkirim.

**Untuk membersihkan baris yang sudah dibatalkan:** klik tombol merah **Hapus dari daftar** pada baris berstatus **Dibatalkan**, lalu konfirmasi. Ini membersihkan catatan antrean yang dibatalkan, bukan menghapus DM di TikTok, data prospek, atau riwayat pesan yang sudah terkirim.

## 11. Membaca ringkasan pekerjaan

| Ringkasan            | Cara membacanya                                                                                                                |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Akun TikTok aktif    | Akun pengirim milik Anda yang aktif.                                                                                           |
| Followers tersimpan  | Data followers yang berhasil diimpor, bukan total followers profil TikTok.                                                     |
| DM terkirim hari ini | Catatan pengiriman pada hari berjalan menurut waktu WIB, termasuk follow-up yang tercatat terkirim. Bukan jumlah pesan dibaca. |
| Perlu diperiksa      | Pengiriman gagal atau hasil yang belum pasti dan perlu Anda tindak lanjuti.                                                    |
| Kuota tugas hari ini | Pemakaian kuota pembuatan tugas, bukan bukti semua tugas sudah terkirim.                                                       |
| Penerima tersedia    | Calon penerima yang memenuhi syarat untuk dipilih. Klik kartu untuk membuka **Antrean prospek** akun yang dipilih.             |

Angka dapat berbeda karena setiap ringkasan menghitung hal yang berbeda. Misalnya, Anda menyimpan 100 followers, membuat 10 tugas, tetapi baru tiga pesan yang tercatat terkirim.

## 12. Kalau ada kendala

| Yang terlihat                                        | Yang perlu dilakukan                                                                                                                                                               |
| ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Akun pengirim belum ada pada pilihan                 | Tambahkan akun di **Akun TikTok** dan pastikan statusnya Aktif. Jika akun milik pengguna lain, hubungi Super Admin.                                                                |
| Followers yang terambil sedikit                      | Pastikan daftar yang dibuka adalah Followers. Periksa apakah TikTok masih memuat daftar. Simpan hasil yang ada; pengambilan tidak menjamin seluruh followers.                      |
| Penerima belum muncul setelah impor                  | Periksa hasil penyimpanan dan akun pengirim yang dipilih. Duplikat, larangan kontak, atau tugas yang masih berjalan dapat membuat penerima tidak tersedia.                         |
| Pesan hanya membuka ruang chat                       | Periksa status dan alasan di MBG. Chat terbuka belum berarti pesan dikirim; extension berhenti jika identitas atau editor tidak dikenali.                                          |
| Identitas pengirim/penerima tidak dapat diverifikasi | Pastikan akun login TikTok cocok dengan dropdown dan username chat cocok dengan penerima. Jika tetap gagal, kirim detail error ke admin.                                           |
| Extension meminta memilih akun                       | Pilih akun pengirim di dropdown MBG, tutup popup, lalu buka DM Sender lagi **dari tab Outbound**.                                                                                  |
| Tidak ada tugas dalam antrean                        | Periksa akun yang dipilih dan panel Status pengiriman. Gunakan **Masukkan ke antrean**; untuk pesan lama yang belum diantrekan, gunakan **Masukkan pesan ke antrean** bila muncul. |
| Tombol tinjau/pengiriman tidak aktif                 | Pilih penerima, periksa sisa kuota, status akun, panjang pesan, serta variabel nama/link yang belum tersedia.                                                                      |
| Nama atau link masih berupa tanda kurung             | Perbaiki template sesuai contoh placeholder dan periksa pratinjau. Pesan lama yang telanjur terkirim tidak otomatis berubah.                                                       |
| TikTok meminta login, verifikasi, atau menolak akses | Hentikan pengiriman, buka TikTok secara manual, dan selesaikan pemeriksaan yang diminta. Jika tetap gagal, minta bantuan admin.                                                    |
| Dashboard meminta login ulang                        | Login kembali, pilih akun pengirim, lalu periksa status terakhir sebelum melanjutkan extension. Jangan langsung membuat kiriman baru.                                              |

Saat meminta bantuan, sertakan username pengirim, username penerima, waktu kejadian, dan screenshot pesan error. Jika admin meminta diagnostik chat: aktifkan tab chat TikTok yang bermasalah, buka DM Sender, lalu klik **Unduh diagnostik chat TikTok**. Bagikan file hanya kepada petugas yang menangani. Jangan mengirim password, kode verifikasi, atau isi konfigurasi aplikasi.

## Checklist sebelum dan sesudah pengiriman

Sebelum mulai:

- [ ] Login MBG dengan pengguna Anda sendiri.
- [ ] Pilihan akun pengirim cocok dengan akun login TikTok.
- [ ] Penerima, isi pesan, nama, dan link sudah diperiksa.
- [ ] Pesan sudah masuk antrean dan DM Sender dimulai dari tab Outbound.

Sebelum selesai bekerja:

- [ ] Periksa pesan gagal dan hasil belum terverifikasi.
- [ ] Hentikan extension dan batalkan antrean menunggu jika pengiriman tidak akan dilanjutkan.
- [ ] Simpan hasil pengambilan followers yang masih diperlukan.
- [ ] Keluar dari MBG, terutama jika komputer dipakai bersama.
